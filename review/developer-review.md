## Part B. 해외 이벤트 에이전시/프로덕션 (6개)

---

### B1. Superfly
- **판정: 유지**
- 풀스크린 비디오 배경 + 스크롤 전환의 안정적 구현, 라이브 이벤트 에너지를 웹으로 전달하는 패턴이 직접적으로 참고 가능
- **기술 참고 포인트**: 비디오 배경 히어로의 모바일 대응 전략 (모바일에서 정적 이미지 폴백 vs 경량 영상), 파워풀한 페이지 전환 트랜지션 구현

### B2. Live Nation Entertainment
- **판정: 유지**
- 대형 영상 히어로 + 통계 수치 오버레이 조합은 콘서트파티의 실적 강조 요구와 일치
- **기술 참고 포인트**: 영상 위 텍스트/수치 오버레이의 가독성 처리 (그라데이션, 블러 등), 카운트업 애니메이션 구현

### B3. Live Nation Productions
- **판정: 유지**
- 시네마틱 다크 톤 영상 중심 구성이 공연 프로덕션 분위기를 잘 전달
- **기술 참고 포인트**: 다크 톤 배경에서의 영상 최적화 (인코딩 설정, 컬러 프로파일), 시네마틱 전환 효과의 CSS/GSAP 구현

### B4. CJ ENM Performing Arts
- **판정: 제거**
- A1의 CJ ENM과 중복되며, 공연 포스터 갤러리 + 호버 효과 수준으로 추가적인 기술 참고 가치 낮음

### B5. CGHERO
- **판정: 유지**
- 3D/VFX 프로덕션을 웹에서 쇼케이스하는 방식이 3D 히어로 구현의 직접적 레퍼런스
- **기술 참고 포인트**: 3D 렌더링 결과물을 웹에 최적화하여 표시하는 방식, WebGL 기반 인터랙티브 쇼케이스의 로딩 전략

### B6. Bizzabo
- **판정: 제거**
- SaaS 플랫폼 UI로 콘서트파티의 포트폴리오/회사소개 목적과 성격이 다르고, 3D 히어로와 무관

## Part C. 3D 모션이 인상적인 에이전시/엔터테인먼트 (6개)

---

### C1. Lusion
- **판정: 유지**
- Three.js/WebGL 기반 풀스크린 인터랙티브 3D 환경의 최고 수준 레퍼런스, Awwwards 수상작
- **기술 참고 포인트**: Three.js 씬 구성 및 최적화 패턴, 마우스 인터랙션 반응형 3D 파티클/형상 구현, 모바일에서의 WebGL 폴백 전략 (GPU 성능에 따른 단계적 저하). 단, 이 수준의 완전한 재현은 전문 WebGL 개발자가 필요하므로 "영감 + 부분 적용" 관점으로 참고

### C2. Active Theory
- **판정: 유지**
- 3D 공간에서의 조명/네온 연출이 콘서트 무대 컨셉과 직결
- **기술 참고 포인트**: WebGL 기반 3D 공간 + 조명 효과 구현 (PointLight, SpotLight 활용), 이머시브 내비게이션 패턴. 풀 3D 공간 구현은 비용이 높으므로 조명/네온 효과 부분만 선택적 적용 권장

### C3. Noomo Agency
- **판정: 유지**
- 3D 스토리텔링 기반 스크롤 경험이 "행사 기획 스토리" 전달에 참고 가능
- **기술 참고 포인트**: ScrollTrigger + Three.js 연동을 통한 스크롤 기반 3D 씬 전환, 스토리텔링과 결합한 인터랙티브 경험 설계 패턴

### C4. Epic (Digital Innovation Agency)
- **판정: 유지**
- 포트폴리오/케이스 스터디의 시네마틱 전환이 가장 정교한 레퍼런스
- **기술 참고 포인트**: GSAP/Framer Motion 기반 정밀한 타이밍 제어 (stagger, ease 커스텀), 이미지 로딩과 애니메이션의 동기화 처리, 텍스트 리빌 타이밍 패턴. 3D보다 2D 모션 중심이므로 구현 난이도가 상대적으로 낮아 예산 대비 효과가 큼

### C5. BDSN Club
- **판정: 유지**
- 제너레이티브 아트/파티클 효과가 콘서트 조명 연출 컨셉에 직접 활용 가능
- **기술 참고 포인트**: Canvas/WebGL 기반 제너레이티브 파티클 시스템 구현, 마우스 인터랙션에 반응하는 파티클 물리 시뮬레이션. 파티클 시스템은 비교적 가벼운 WebGL 구현으로 성능/비용 면에서 현실적

### C6. Resn
- **판정: 제거**
- 전체 사이트가 게임적 인터랙티브 경험으로 구성되어 실험적 성격이 강함. 콘서트파티의 포트폴리오/회사소개 목적과 괴리가 크고, 이 수준의 구현은 예산/일정 면에서 비현실적

## 개발자 종합 의견

### 3D 히어로 구현 현실적 접근 제안

예산/일정이 미확인 상태이므로 단계별 접근을 권장합니다:

1. **현실적 1순위 (GSAP + 경량 WebGL)**: Epic(C4)의 시네마틱 모션 + BDSN Club(C5)의 파티클 효과를 조합. GSAP ScrollTrigger 기반 텍스트/이미지 연출에 Canvas/WebGL 파티클을 히어로 배경으로 사용. 구현 난이도 중간, 모바일 대응 양호.

2. **이상적 2순위 (Three.js 3D 씬)**: Lusion(C1) + Active Theory(C2) 참고. Three.js 기반 3D 무대 조명 연출. 전문 WebGL 개발 경험 또는 추가 리소스 필요, 모바일에서는 단계적 품질 저하(progressive degradation) 필수.

3. **안전한 대안 (영상 + 모션)**: Superfly(B1) + Live Nation(B2,B3) 참고. 고품질 영상 배경 + GSAP 텍스트/UI 애니메이션. 구현 난이도 낮음, 모바일 대응 용이, 콘텐츠(영상) 품질에 의존.

### 성능 고려사항
- 3D/WebGL 적용 시 모바일 GPU 성능 감지 로직 필수 (navigator.gpu 또는 벤치마크 기반)
- 히어로 영상 사용 시 모바일에서는 poster 이미지 폴백 권장
- Core Web Vitals (LCP, CLS, INP) 기준 충족을 위한 로딩 전략 설계 필요
